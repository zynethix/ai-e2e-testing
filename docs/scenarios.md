## 素材

一律运行时生成纯色图，不用网上样张——像素断言需要干净背景，纯色图让「卡片区有内容 / 空白区纯白」成为可判据。

| 代号 | 规格 | 用途 |
|---|---|---|
| G1 | 纯红 3600×2000 | 正面。长边 3600 使最大裁剪框高度顶满 2000，远超输出所需 638，不触发画质不足 |
| G2 | 纯蓝 3600×2000 | 反面。与 G1 不同色，便于在导出文件里区分上下两张卡片 |

投递方式：构造 File 后经 DataTransfer 塞进 `#front-input` / `#back-input` 并触发 change（被测项目设计文档 §15 末段给的办法），由自定义 Node `genSolidImage` 封装。

## 由本表确定的自定义 Node 清单（Task 2 据此实现）

| Node | 职责 |
|---|---|
| genSolidImage | 生成纯色图，经 DataTransfer 投递到指定 file input 并触发 change |
| readPageState | 读页内 state 与 DOM 属性（徽标文字、disabled、checked、cropper.box） |
| acceptDialog / dismissDialog | 接原生 confirm，记录文案与调用次数 |
| captureDownload | 截获下载，产出文件名与字节 |
| analyzePdf | 解 PDF 字节：页数、MediaBox、内嵌图像尺寸 |
| analyzePixels | 字节回灌浏览器解码后按矩形采样（卡片位置、边框、空白区纯白、水印有无） |
